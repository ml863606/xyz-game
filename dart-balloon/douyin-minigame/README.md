# 飞镖扎气球 - 抖音小游戏工程

这个目录是可直接导入抖音开发者工具的原生小游戏版本。

## 导入方式

1. 打开抖音开发者工具。
2. 选择「小游戏」项目。
3. 项目目录选择：
   `D:\WorkSpace\mxl\xyz\xyz-game\dart-balloon\douyin-minigame`
4. AppID 可先选择测试号/游客模式，正式上传时替换为控制台里的小游戏 AppID。
5. 编译运行。

## 说明

- 入口文件：`game.js`
- 配置文件：`game.json`
- 工程配置：`project.config.json`
- 竖屏 Canvas，适配手机屏幕。
- 不依赖后端、广告、排行榜、图片、音频或 DOM。
