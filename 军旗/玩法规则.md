# 童年纯格子简化版军棋玩法规则

## 版本定位

本玩法采用民间地摊翻棋风格，是纯格子简化版军棋。

- 无军旗
- 无铁路
- 无行营
- 无大本营
- 保留地雷
- 保留炸弹
- 第一次翻出的颜色就是玩家阵营

## 棋盘

棋盘为普通方格棋盘，只存在上下左右相邻关系。

棋子只能在方格之间移动，不存在铁路直行、铁路转弯、行营保护、大本营限制等特殊地形规则。

推荐使用 6 x 8 棋盘，容纳双方各 24 枚棋子，共 48 枚。这个尺寸比口袋版更接近传统翻军棋的密度，也更适合保留地雷和炸弹后的完整博弈。

## 棋子配置

双方各使用一套相同棋子，颜色分为红方和蓝方。

每方棋子推荐如下：

| 棋子 | 数量 | 是否可移动 |
| --- | ---: | --- |
| 司令 | 1 | 是 |
| 军长 | 1 | 是 |
| 师长 | 2 | 是 |
| 旅长 | 2 | 是 |
| 团长 | 2 | 是 |
| 营长 | 2 | 是 |
| 连长 | 3 | 是 |
| 排长 | 3 | 是 |
| 工兵 | 3 | 是 |
| 炸弹 | 2 | 是 |
| 地雷 | 3 | 否 |

如需更接近传统军棋数量，可扩展棋盘并增加棋子，但本版本以短局、好懂、快翻快吃为目标。

## 开局

1. 将双方全部棋子背面朝上混合。
2. 随机铺满棋盘。
3. 游戏开始时，所有棋子均为暗棋。
4. 玩家轮流行动。

## 阵营确定

第一次被翻开的棋子的颜色，决定当前翻棋玩家的阵营。

示例：

- 玩家 A 第一次翻开红色棋子，则玩家 A 为红方，玩家 B 为蓝方。
- 玩家 A 第一次翻开蓝色棋子，则玩家 A 为蓝方，玩家 B 为红方。

阵营确定后不可更改。

如果第一步翻出的棋子是炸弹或地雷，仍按该棋子的颜色确定阵营。

## 回合行动

每名玩家在自己的回合只能执行一种行动：

1. 翻开一枚暗棋。
2. 移动一枚己方明棋。
3. 使用一枚己方明棋攻击相邻敌方明棋。

不能在同一回合中同时翻棋和移动，也不能移动后继续攻击。

## 翻棋规则

玩家可以选择任意一枚暗棋翻开。

翻开后，该棋子保持明棋状态，直到被吃掉或游戏结束。

翻出的棋子不一定属于当前玩家。如果翻出的是对方棋子，该棋子也会立即成为对方可用棋子。

## 移动规则

可移动棋子每次只能上下左右移动一格。

移动限制：

- 不能斜走。
- 不能跳过棋子。
- 不能移动到己方棋子所在格。
- 不能移动到暗棋所在格。
- 地雷不能移动。

如果目标格有敌方明棋，则本次行动视为攻击，不是普通移动。

## 军衔大小

普通棋子按以下顺序比较大小：

司令 > 军长 > 师长 > 旅长 > 团长 > 营长 > 连长 > 排长 > 工兵

判定规则：

- 大棋可以吃小棋。
- 小棋不能吃大棋。
- 同级相遇，双方同时移除。
- 工兵等级最低，但可以排除地雷。

## 攻击规则

己方明棋可以攻击上下左右相邻的一枚敌方明棋。

攻击后按棋子规则结算：

- 攻击方大于防守方：防守方移除，攻击方移动到目标格。
- 攻击方小于防守方：攻击方移除，防守方留在原地。
- 双方同级：双方同时移除，目标格变空。
- 炸弹参与战斗：双方同时移除。
- 工兵攻击地雷：地雷移除，工兵移动到目标格。
- 非工兵攻击地雷：攻击方移除，地雷留在原地。

暗棋不能被攻击，必须先被翻开。

## 炸弹规则

炸弹为可移动棋子，每次上下左右移动一格。

炸弹攻击任意敌方明棋时，双方同时移除。

任意敌方明棋攻击炸弹时，双方也同时移除。

炸弹可以炸地雷，结算为炸弹和地雷同时移除。

## 地雷规则

地雷为不可移动棋子。

地雷只能在被翻开后参与结算。

地雷结算规则：

- 工兵可以排雷，工兵吃掉地雷并移动到地雷所在格。
- 炸弹可以炸雷，炸弹和地雷同时移除。
- 其他棋子攻击地雷时，攻击方移除，地雷保留。

## 胜负条件

满足以下任一条件时，游戏结束：

1. 一方所有可移动棋子都被移除，另一方获胜。
2. 一方轮到行动时，没有任何合法行动，该方失败。
3. 棋盘上只剩双方都无法形成有效攻击的棋子时，可判定为和棋。

可移动棋子包括普通军衔棋子和炸弹，不包括地雷。

## 和棋建议

为避免残局拖延，可以加入以下任一限制：

- 连续 40 回合没有吃子，则判和。
- 双方只剩地雷或无法互相攻击的棋子，则判和。
- 双方玩家都选择求和，则判和。

## 实现口径

开发时建议将棋子状态拆分为：

- 颜色：红方、蓝方
- 类型：司令、军长、师长、旅长、团长、营长、连长、排长、工兵、炸弹、地雷
- 明暗：暗棋、明棋
- 是否可移动：地雷不可移动，其他棋子可移动
- 所属阵营：由第一次翻出的棋子颜色确定

每回合行动流程：

1. 检查当前玩家是否已有阵营。
2. 玩家选择翻棋、移动或攻击。
3. 如果是首次翻棋，根据翻出的棋子颜色确定双方阵营。
4. 执行动作并结算棋盘变化。
5. 检查胜负或和棋条件。
6. 切换回合。
