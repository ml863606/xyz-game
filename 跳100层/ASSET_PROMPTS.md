# Asset Prompt Library

这些提示词用于生成新素材时的基础质量约束。生成结果必须作为独立素材文件进入 `assets/`，代码只引用资源路径。

## 道具 / 图标

2K 高清游戏道具图标，主体居中，结构规整，材质清晰，金属、宝石、布料质感区分明确，干净白底，柔和定向光，边缘锐利，无模糊、无噪点、无畸形、无多余杂乱细节。

适用范围：

- UI 道具图标
- 检查点徽章
- 弹跳板、机关、钥匙、奖杯等图标
- 后续可转为 SVG 或 PNG 后放入 `assets/ui/icons/` 或 `assets/sprites/`

## 角色立绘

2K 高清游戏角色立绘，人体比例标准，五官协调，肢体结构正确，服装层次清晰，材质表现干净，光影柔和统一，背景简洁，避免五官扭曲、肢体畸形、穿模、色彩脏灰、边缘糊化。

适用范围：

- 玩家角色
- NPC / 引导角色
- 失败、通关、结算界面角色图
- 批准后放入 `assets/sprites/characters/`

## 场景原画

2K 高清游戏场景概念图，透视合理，空间层次明确，建筑 / 地形 / 物件结构自然，材质纹理清晰，光影统一，色彩氛围协调，避免画面脏乱、透视错误、边缘模糊、细节堆砌。

适用范围：

- 关卡背景
- 跳台塔身背景
- 菜单 / 结算背景
- 批准后切片或重绘为 `assets/sprites/backgrounds/` 内的可用素材

## 当前项目风格补充

- 2D 横版跳跃，不使用 3D 第一人称素材方向。
- 形状要清楚，轮廓要硬，角色和平台在运动中一眼能读懂。
- 游戏内小尺寸素材优先考虑 SVG 源文件；复杂原画可保留 PNG/WebP 成品，并配套源提示词。
- 每个新增素材都应在 `ASSETS.md` 或对应目录说明中记录用途和引用位置。
